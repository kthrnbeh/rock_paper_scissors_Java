# Overview

In this is a ROCK-PAPER-SCISSORS program written in Java. There are two players playing at once, the user, selects either computer or chooses a second player. Three rounds are played and who ever wins 2 rounds wins. There is a history of winners at the end, and you can play multiple rounds if you choose. The rounds are recorded unless you ask them  to be deleted. 
Writing this software was for fun, and because in my family we commonly use ROCK-PAPER-SCISSORS to determine who gets things, or has to do what.
